# ☕ Java POO — Ejercicios Prácticos

> Repositorio dedicado a la resolución de ejercicios prácticos de **Programación Orientada a Objetos (POO)** en Java, aplicando conceptos fundamentales como clases, atributos, métodos y encapsulamiento.

---

## 📚 Ejercicios

### Ejer01 — Clase `Triangulo`
Clase con atributos `base` y `altura`. Incluye un método para calcular el **área** del triángulo.

### Ejer02 — Clase `Numero`
Clase con atributo `numeroReal`. Incluye métodos para calcular el **cuadrado** y el **cubo** del número.

### Ejer05 — Clase `Cilindro`
Clase con atributos `radio` y `altura`. Incluye un método para calcular el **volumen** del cilindro.

### Ejer06 — Clase `TrianguloRectangulo`
Clase con atributos `cateto1` y `cateto2`. Incluye métodos para calcular el **área**, la **hipotenusa** y el **perímetro**.

### Ejer07 — Clase `ConversionTemperatura`
Clase con atributo `temperatura` en grados Celsius. Incluye un método para convertir a **grados Fahrenheit**.

### Ejer08 — Clase `ConversionLongitud`
Clase con atributo `cantidad` en metros. Incluye métodos para convertir metros a **pies** y a **pulgadas**.

### Ejer09 — Clase `GasIdeal`
Clase con atributos `temperatura`, `numeroDeMoles` y `volumen` (litros). Incluye un método para calcular la **presión** usando la ley del gas ideal.

### Ejer10 — Clase `Movil`
Clase con atributos `velocidadInicial`, `tiempo` y `aceleración`. Incluye un método para calcular el **espacio recorrido** por un móvil.

> 📝 *Los ejercicios Ejer03 y Ejer04 incluyen las clases `Producto` y `Trabajador` respectivamente (ver detalle abajo).*


---

## 🧠 Conceptos de POO aplicados

| Concepto | Descripción |
|----------|-------------|
| **Clases y objetos** | Modelado de entidades del mundo real |
| **Atributos** | Variables que definen el estado de un objeto |
| **Métodos** | Comportamiento y operaciones de cada clase |
| **Encapsulamiento** | Uso de getters y setters para proteger datos |
| **Constructores** | Inicialización de objetos al momento de su creación |

## ▶️ ¿Cómo ejecutar?

```bash
# 1. Clona el repositorio
git clone https://github.com/JohanaQuispe/java-poo-ejercicios.git

# 2. Entra a la carpeta del ejercicio
cd Ejer01

# 3. Compila
javac Triangulo.java

# 4. Ejecuta
java Triangulo
```
